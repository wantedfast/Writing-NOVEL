# 风格引擎：从语料特征到可迁移的叙事动作

## 证据与适用范围

本规则由《龙族》1—4 部约 224 万字符全文统计及跨四部场景精读提炼。统计能描述语料分布，不能证明某个词或标点是作者独有指纹。数字只用于发现异常，不能当生成配额。原著文本不随 Skill 分发。

## 比词句更重要的五个机制

### 1. 笑话是一种自我防卫

视角人物常把失落、恐惧或渴望包装成不正经的反应。他不是每句话都机智；偶尔答不上话，笑才有背后的重量。写清他在乎什么、怕别人发现什么、最后做了什么。关键时刻可以嘴上仍然怂，行动却先一步承担代价。

### 2. 关系由对话和小动作推进

一方严肃、一方拆台的对话能带来节奏，但两人不能都成为同一个段子手。配角要有自己的目标和反差：看似冷硬的人不懂普通社交，看似轻浮的人认真守护某个旧物。亲密或悲伤优先落在日常叮嘱、借口、动作和物件上，不用旁白直接宣告感情。

### 3. 具体世界压住抽象抒情

优先写型号、价格、时间、路线、职业工具、衣物磨损、消息记录等准确细节。它们应当属于当前人物和题材，而非从《龙族》搬运品牌、游戏或校园物件。人物可以用自己熟悉的系统理解事件：程序员用故障排查，演员用走位，航海者用潮汐。参照必须推动判断或情节，仅作点缀会显得刻意。

叙述通常贴着视角人物移动：客观动作写到一半，可以自然滑入他不敢说出口的吐槽或自我贬低，不必每次都加“他想”。偶尔允许叙事者跳远一步，给人物一个带笑的短判断，但不能频繁变成评书旁白。为重要人物保留一套可反复变形的私人意象，使它在不同场景里积累新意义。

### 4. 情绪靠落差，不靠加码

常见有效顺序是轻松交锋、一个先前不起眼的细节改变意义、短暂的沉默或小动作、有人把生活继续下去。允许在高潮前减慢镜头，把光、声、距离和动作写清楚；真正的情绪点尽量短，不追加解释。收尾可以回到玩笑或普通物件，但不能用笑话抹掉刚发生的事。

另一种有效转折发生在旁观者身上：他先带着戒备或成见观察人物，一个微小动作使他重新理解两人的关系，镜头再从这个动作拉远到街道、季节或整座城市。大尺度抒情必须由这次目击挣来，不能在人物行动之前先宣布世界变得美好。

### 5. 宏大由个人代价承担

人物谈命运、世界或牺牲时，用眼前的一次选择支撑主题。长篇宣言和抽象金句容易空泛；一个明知吃亏仍然去做的小动作通常更有力。战争、科幻、悬疑等题材可放大场面，但镜头最终应回到具体的人。

## 按场景切换音量

- 低声量关系戏：日常交锋、误解或照料先行；把旧事藏在一个物件或无意动作里。最动人的一拍可以很短，随后让生活继续。这一档适合暗恋、失去、和解和章节尾声。
- 低声量静场：人物独自进入曾有别人生活的空间，沿着门槛、光线和少量痕迹逐步观察；让感官事实引出不确定的猜测，不要求对话、笑点或戏剧性揭晓。详见 [静场的细腻推进](quiet-scene.md)。
- 高声量危机场景：先说明空间、时限和失败代价，再用光线、声音、速度与动作切片放慢关键瞬间。懂行者可以短暂解释机制，随即回到视角人物的恐惧与选择。人物不能只剩任务身份：危险结束后，若这一幕承担关系变化，留一点低声量时间让一个日常习惯或先前细节得到新意义，不必在动作最急处插入大段回忆。允许人物喊叫和激烈标点，但不能全篇保持峰值。
- 群像喜剧：让制度、职业规程或重大仪式与人物的小算盘相撞。旁观者视角能制造错位；玩笑必须揭露关系或推动局势，而非中断故事。

三档可在同一章交替。原语料的强项是振幅：喧闹之后忽然安静，宏大场面最后落到一个人身上。不要把“克制”误解为始终低音量。

## 两个自造的微型示范

这些示范只说明叙事动作，不提供可复制的人物、设定或句子。

- **人物嘴上退缩，行动先出卖他。** “那扇门后面有水，我可不会游泳。”值班员把钥匙交给同伴，自己却先摸到了门闩。他没有解释为什么；同伴看见他口袋里露出一角湿透的儿童画。
- **让情绪落回具体工作。** 维修师傅一向嫌学徒话多。事故过去后，他把备用手套丢给学徒，说下一班记得把扳手归位。学徒照办，发现工具柜里已经替他留好了名字。

若把示范里的门、水、儿童画或手套直接换名搬进新稿，便失去了迁移价值；应从新人物自己的经历和职业中寻找相应的动作与物件。

## 语言与节奏

句长、标点和显式比喻不决定一段是否细腻。先按场景判断人物、空间与情绪是否成立；只有诊断长稿表层失衡或比较同类场景时，才读取 [语料节奏观察值](corpus-rhythm.md)。不要在起草时把统计数字当成生成目标。

## 常见失败

- 每个角色都吐槽，失去对位与人物差异。
- 连续抛梗，人物受伤后马上用笑话否认情绪。
- 用“孤独、命运、守护”等抽象词代替场景铺垫。
- 解释泪点，或用一句海报式宣言替代具体行动。
- 借用原作专有的游戏梗、角色隐喻、标志性台词和情节机关，导致原创故事变成换名复述。
- 把统计指标写成硬约束，造成标点、短段、比喻堆砌。
