# 前向评测套件

用于审查或改版技能，不是每次写作都要执行。评测目标是证明技能能根据场景切换叙事声部，而不是只会重复一篇漂亮的离别关系戏。

## 测试集

每次大改后，从下列六类各生成一个 600—1000 字的原创场景。题材、人物和关键物件不得沿用既有校准样稿。

1. 关系戏：两个互相在乎的人共同完成一件小事，其中一人即将离开，但禁止使用车站、落日、胶卷和闹钟。
2. 静场：人物独自进入已经离职同事的工作间，只能根据现场痕迹修正判断，禁止信件或日记解释。
3. 群像喜剧：一个高度正式的机构第一次执行荒唐的新规，至少三人目标不同，笑点必须推动决策。
4. 危机战斗：狭窄空间内的救援，写清站位、时限和一个决定成败的专业机制，禁止用宣言结束。
5. 神话恐怖：某个巨大存在进入现代城市，先由日常尺度比较，再落回一个普通人的身体反应与选择。
6. 都市传奇：一名掌握资源的人提出真正诱人的交易；对话双方都必须聪明，权力由具体细节建立。

## 评分维度

每项 0—2 分，总分 12 分；任一维度为 0 都视为失败。

- 模式命中：场景的注意力和落点符合所选模式。
- 人物声音：主要人物的语言目标和认知框架可以区分。
- 具体世界：细节属于当前职业、时代和地点，并参与判断或行动。
- 信息调度：读者先看见事实，再随人物改变理解；站位和物件连续。
- 情绪与代价：情绪由铺垫和选择挣来，没有解释泪点或海报式宣言。
- 原创差异：没有搬用原作专名、标志性台词、连续情节或校准样稿结构。

## 跨样本失败项

六个样本还要一起检查：

- 是否四篇以上都采用“简单任务—重复词—环境关闭—小动作”同构结构；若是，说明关系戏协议污染了其他模式。
- 是否四篇以上都由同一种自嘲男主发声；若是，说明人物机制被误写成固定人设。
- 是否短段比例普遍触发审计脚本警报；若是，先合并自然语义单位，不靠增加长句硬凑。
- 是否所有高潮都依赖光线熄灭、声音停止或世界静止；若是，说明电影感已经模板化。

通过标准：每篇至少 9/12，且没有跨样本失败项。统计脚本只提供表层证据，最终仍需逐篇阅读判断。
